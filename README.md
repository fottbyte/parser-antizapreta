Антизапрет хранит список сайтов в профиле браузера, и этот список не удаляется даже когда расширение
заблокировано (из-за перехода браузера на MV3). Скрипт тупо парсит прфиль и достает список сайтов.

## Что нужно

- Windows
- Node.js 18+ (скачать LTS: https://nodejs.org — при установке оставить галочку «Add to PATH»)
- Интернет один раз (скрипт сам поставит маленькую зависимость `classic-level`)

## Далее

1. Поместите файл в любое место на пк
2. Откройте командную строку в этой папке (ПКМ по папке → «Открыть в Terminal»)
4. Вводим в консоль:

   ```
   node parser.js
   ```

   Скрипт сам найдёт профили браузеров (Яндекс, Chrome, Chromium, Vivaldi,
   Brave и т.д все, что на базе хромиума) и скопирует список из первого, где он есть.

   Если профиль не найден укажите путь явно:

   ```
   node parser.js "C:\Users\ВАШ_НИК\AppData\Local\Yandex\YandexBrowser\User Data\Default"
   ```

5. Готовые файлы появятся в `result\`:

   - `antizapret_sites_plain.txt` — список построчно (`*.chatgpt.com`, ...)
   
   - `antizapret_hosts.json` — тот же список в формате
     `{host, scope:"domain", enabled:true, mode:"proxy"}` - для импорта в расширение от https://github.com/aVitomin/runet-censorship-bypass
   
   - `pac_mods_full.json` — полная копия всех настроек: свойства прокси
     (`customProxyStringRaw`), флаги, домены `moreDomains`.

## На заметку

- Скрипт работает по **копии** базы (файлы профиля не меняются), ничего не
  удаляет
- Если скрипт пишет «список не найден» — значит хранилище расширения было
  очищено (например кнопкой сброса в Troubleshoot), восстановить его уже нельзя.
- Прокси-ключи (`PROXY ...@IP:PORT`) из `pac_mods_full.json` — приватные
  учётные данные, в чат/файлами с другими не отправляйте.
